## 6. Top 3 competitors / substitutes
1. **Fiverr budget Excel cleaners** (~50,500 gigs), $5-50, 1-3 days. Weakest point: commodity output, no analysis, trust/communication issues.
2. **ChatGPT / Claude / Copilot (DIY AI)**, free-$20/mo. Weakest point: messy data and silently wrong totals; buyer does the work and owns the risk.
3. **Upwork catalog cleanup sellers**, $25-200, 24h, some already include a change log or audit sheet. Weakest point: still "clean file only"; no report or plain-English summary.

## Positioning map (text)
Axis X: DIY tool -> done for you. Axis Y: raw clean file -> finished, verified report.
- Bottom-left: Power Query, Copilot, ChatGPT (DIY, raw).
- Bottom-right: Fiverr $5-30 cleaners (done for you, raw).
- Top-left: Etsy dashboard templates (DIY, finished look, buyer's data not in it).
- Top-right, thinly occupied: $100-200+ dashboard builders, multi-day delivery.
- **Open spot:** done for you + finished verified report + 24h + under $100.

## The gap a zero-reputation seller can own (recommendation, conf. M)
"Messy export in, **checked** report out in 24h": cleaned file + pivot/charts + a 5-line plain-English summary + a **reconciliation sheet** (every total ties back to the raw file) + change log. Fixed price by rows. Clear data-handling note (delete files after delivery). Sells against the two strongest buyer fears found: wrong numbers (AI) and silent sellers (Fiverr).
Not unique on its own (some Upwork sellers already offer audit sheets), so the edge is the bundle + speed + summary, not any single feature. Easy to copy; YouTube channel is the long-run moat.

**Starting price range (guess, for founder-pricing / CFO to test):**
- Basic: clean up to ~2,000 rows + summary, 24h: **$25-35** (net $20-28 on Fiverr)
- Standard: + pivot report and 2-3 charts: **$50-75**
- Premium: + one-page dashboard: **$100-150**
Below $25 competes with ~50k sellers at $5-15; above $75 for basic needs reviews we do not have yet.

## Threats
- Any Fiverr seller can add "AI summary + checks" in a day.
- Microsoft improving Copilot Clean Data for messy files.
- Confidential data in customer files: get a professional view on data-protection obligations before taking payroll/bank files. Not legal advice.
